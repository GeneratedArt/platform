0. Source-of-truth context for the agent (read this first)
You are working in GeneratedArt/platform, a monorepo that was hard-reset on April 23 2026 to a upstream template Jekyll v2 template foundation. Do not reintroduce removed surfaces. Layer new features onto the upstream template template's existing collections (_authors, _portfolio, _shop_items) and Cloudflare Worker — do not fork to Astro, Next.js, Vercel, Pages, or any other host.
Architectural commandments (non-negotiable):
One static-site target: GitHub Pages (Jekyll, built by .github/workflows/pages.yml).
One dynamic service: Hono Worker at workers/api/, deployed to api.generatedart.com.
Smart contracts: Foundry suite under contracts/, deployed to Base mainnet (8453) + Base Sepolia (84532).
No AWS, Vercel, Firebase, Supabase, Mongo, Node.js server, Stripe-as-primary, Cloudflare Pages, Netlify. Disable Cloudflare Workers Builds auto-deploy in the dashboard before touching the Worker — it currently tries to run npx bundle exec jekyll build and fails the deploy.
The platform never holds private keys. All wallet operations are client-side via WalletConnect v2 + viem + wagmi. SIWE (Sign-In with Ethereum) for auth. The Worker only verifies signatures.
Repos are first-class. Each artist project is a real GitHub repo under the GeneratedArt-artists org. The platform is a meta-layer over git. No private database of source code; source lives where source belongs.

1. The architectural insight that defines this project
Every artist project is a GitHub repo. Every collaboration is a fork or a PR. Every mint is a tagged commit pinned to IPFS.
This is what makes GeneratedArt structurally different from fxhash/Art Blocks:
Source code is public-by-default and lives in git, not in a proprietary DB.
Forks = remixes with automatic on-chain royalty attribution to the original author.
PRs = collaboration — non-coder briefs, coder responses, gallery curation all happen as issues/PRs.
GitHub Pages = free preview hosting for every sketch, on every branch.
GitHub Actions = free CI for thumbnail generation, frozen-artifact bundling, IPFS pinning.
Stars/forks = native social graph the platform piggybacks on.
The Worker becomes a thin authoritative index + signer, not a content store.

  id            TEXT PRIMARY KEY,

CREATE TABLE applications (
  id            TEXT PRIMARY KEY,
  brief_id      TEXT NOT NULL REFERENCES briefs(id),
  applicant     TEXT NOT NULL REFERENCES users(address),

CREATE TABLE galleries (
  id            TEXT PRIMARY KEY,
  curator       TEXT NOT NULL REFERENCES users(address),

  id            TEXT PRIMARY KEY,

3. Smart contract design (Foundry, Solidity 0.8.24)
Four contracts, all on Base. Keep them small, audited-shape, and upgradeable only via factory replacement (no proxies).
3.1 GAProjectFactory
Deploys one GAProject clone (EIP-1167 minimal proxy) per project.
Records mapping(bytes32 projectId => address project).
Emits ProjectCreated(bytes32 id, address project, address artist, address splits).
3.2 GAProject (ERC-721 + ERC-2981)
One contract per project. Edition size set at deploy (e.g. 100, or open).
mint(bytes32 seed) payable: stores tokenIdToSeed[id] = seed. Seed is the only thing needed to deterministically reproduce the artwork given the frozen bundle CID.
tokenURI(id): returns ipfs://{frozenCID}/?seed={seed} (HTML lives in the frozen bundle and reads ?seed=…).
ERC-2981 royalty receiver = the project's GASplits instance.
setBaseFrozenCID(string) callable once by artist after deploy, then locked.
3.3 GASplits
Pull-based payment splitter (à la 0xSplits / OpenZeppelin PaymentSplitter semantics, immutable shares).
Default split for solo artist mint: 90% artist, 5% gallery (if any), 5% protocol treasury.
Default split for collab mint: configurable on factory call, e.g. 60% coder / 25% non-coder collaborator / 5% gallery / 10% protocol — total must equal 10000 bps.
Each shareholder pulls via release(token, account).
3.4 GAGalleryRegistry
register(string name, string city) — anyone can register, but a multisig-controlled verify(address) flag gates the ability to be selected as the gallery for a project's splits.
Emits GalleryRegistered, GalleryVerified, GalleryRevoked.
Why this shape: ERC-721-per-project is the Art Blocks pattern. On-chain seed + off-chain frozen bundle is the fxhash pattern. Splits-as-receiver is what makes collaboration & gallery splits trustless without us holding funds.

4. Feature breakdown
For each feature: (1) implementation, (2) contracts, (3) flow, (4) impact, (5) risks/metrics.
Assumption flag: the feature list below is reverse-engineered from the request prose. Update §4 if your real list differs.
F1 — Repo-as-Project (foundation)
Impl. Worker calls GitHub POST /repos/{template_owner}/{template_repo}/generate using a fine-grained PAT (org-scoped, Contents+Workflows R/W). Repo is created under GeneratedArt-artists/{handle}-{slug}. D1 row inserted. Optional GitHub App later for per-user OAuth instead of central PAT.
Contracts. None at this stage. Project address only minted at §F8.
Flow. Studio → "New project" → name + engine + license → spinner → repo opens in studio iframe.
Impact. Zero lock-in. Source code, history, issues, stars all live in GitHub forever.
Risks. GitHub rate limits (mitigated: PAT is org-scoped, requests batched). PAT compromise (mitigated: fine-grained, rotated quarterly, never in client). Metric: repo creation success rate > 99%, p95 latency < 1.5s.
F2 — Artist profile / portfolio (/@:handle)
Impl. upstream template's _authors/{handle}.md is the canonical profile front-matter (name, bio, avatar, socials). The portfolio page is a Jekyll layout that fetches /v1/users/:handle/projects at build (via jekyll-data plugin OR client-side JS — pick client-side so the site doesn't rebuild on every project change).
Contracts. None.
Flow. Visit /@dami → static shell renders → JS fetches projects + follow count → grid of cover images (R2-hosted) → click into project page.
Impact. Free, fast, SEO-friendly portfolio every artist gets the day they sign up. The portfolio IS the platform's growth surface.
Risks. Stale cache vs. fresh writes (mitigated: KV cache with Cache-Control: max-age=60, stale-while-revalidate=600). Metric: portfolio render < 200ms TTFB, > 90 Lighthouse.
F3 — Sketch Studio (/studio)
Impl. CodeMirror 6 editor + iframe sandbox. Engine adapters: p5.js, three.js, raw GLSL via a tiny WebGL shell. "Save" POSTs to /v1/projects/:id/commit which forwards to GitHub Contents API. Live preview re-runs on save. Hotkeys: ⌘S commit, ⌘E export PNG (R2 upload via signed URL).
Contracts. None.
Flow. Pick template → edit → ⌘S → commit lands in artist repo with auto-message "studio: {date}" → preview reloads.
Impact. Lowers the entry barrier. Coders who don't want to set up local tooling can ship.
Risks. Sandboxing (mitigated: iframe with strict CSP, no parent access). Lost work (mitigated: localStorage autosave every 5s, debounced commit on blur). Metric: commits/session, return rate D1/D7.
F4 — Project management
Impl. D1-backed CRUD on metadata only — title, description, license, cover, status. Code edits go through F3 or directly on GitHub (we surface the GitHub link prominently). "Delete" archives the repo (GitHub archive: true) and sets D1 status archived — never deletes git history.
Contracts. None.
Flow. Dashboard at /dashboard/projects lists all projects with status badges (draft / published / minted / archived).
Impact. Artist control without us controlling their work.
Risks. None significant. Metric: projects per active artist > 3 within 30 days.
F5 — Follow graph + activity feed
Impl. Insert/delete on follows table. Activity feed query: SELECT * FROM events WHERE actor IN (followees of :me) ORDER BY created_at DESC LIMIT 50. Events are written by webhooks (GH push), Worker actions (project create/mint), and indexer (Base events).
Contracts. None — but mint events flow through indexer.
Flow. /feed → infinite scroll of "X published Y", "X minted Y #3", "X applied to brief Z".
Impact. Retention loop. Without a feed, the site is a directory; with a feed, it's a community.
Risks. Spam (mitigated: rate limit creates per address, exclude unverified accounts from public feed). Metric:WAU/MAU, feed visits per session.
F6 — Collaboration Lounge (artist ↔ artist)
Impl. Briefs table with industry='collab'. PR-driven workflow: applicant forks the artist's repo, opens PR, the platform tracks pull_request webhook events. When merged, a GASplits deployment is suggested (artist + collaborator at agreed bps).
Contracts. GASplits deployed at the moment the merged collab is published.
Flow. Artist posts collab brief → coder/non-coder applies → DM unlocks → fork + PR → merge → deploy splits → mint ready.
Impact. This is the wedge. fxhash and Art Blocks have no native collaboration primitive. We do, and it's trustless.
Risks. Disputes over contribution (mitigated: PR diff is the canonical record, splits ratio is signed by both before merge). Metric: % of mints that are collabs, target > 20% by month 3.
F7 — Industry briefs (textile / fashion / architecture / product)
Impl. Same briefs table, different industry value. Brief poster doesn't need to be a coder — they sign in with a wallet (or email-based passkey for a v2 onboarding flow), describe the need, attach reference images (R2). Coders apply with a sample project + pitch.
Contracts. Optional escrow: GAEscrow (v2) holds budget until milestone signed by both. Out of scope for 24h.
Flow. /briefs filtered by industry → click brief → "Apply" → pitch + sample → notification to poster → off-platform agreement → on-platform mint with splits.
Impact. Opens generative art to revenue streams beyond NFT speculation: pattern licensing for textile, parametric facades for architecture, motion identities for fashion brands.
Risks. Off-platform deals leak (mitigated v2: optional escrow + reputation score). Metric: briefs posted per week, application rate, paid match rate.
F8 — NFT minting
Impl. Mint UI at /mint/:projectId. Connect wallet → fetch project → if not yet deployed, call factory.createProject(...) (artist signs, pays gas only). Frozen bundle is required before mint: F11 must complete first. Per-token mint calls project.mint(seed) with seed = keccak256(blockhash || msg.sender || tokenId).
Contracts. GAProjectFactory.createProject → returns GAProject clone + GASplits clone.
Flow. Artist clicks "Deploy" once → contract live → opens public mint page → collector connects wallet → mints → tokenURI resolves to IPFS frozen bundle with ?seed= param → artwork renders.
Impact. This is the revenue moment. 5% protocol fee via splits, default 5% to gallery if attached.
Risks. Gas spikes on Base (mitigated: factory uses minimal proxies, ~50k gas per project deploy). Failed mints (mitigated: simulation step in UI before signing). Metric: primary mint volume, secondary royalty volume, protocol revenue.
F9 — Royalty splits
Impl. GASplits deployed alongside GAProject. ERC-2981 royaltyInfo(_, salePrice) returns (splitsAddr, salePrice * 5%) — marketplaces honor this. Splits are pull-based; UI shows balance and a "Withdraw" button.
Contracts. GASplits (above).
Flow. Sale on OpenSea/Zora/Magic Eden → royalty flows to GASplits → each shareholder withdraws → tx visible on dashboard.
Impact. Trustless multi-party royalties make collabs and gallery deals frictionless.
Risks. Marketplaces ignoring royalties (industry-wide problem; document the on-chain enforcement we do support, accept the rest). Metric: royalty volume / total secondary volume.
F10 — Gallery partnerships
Impl. GAGalleryRegistry on-chain + galleries table off-chain (mirrored). Galleries register, get verified by multisig, and can be attached to a project at deploy time as a shareholder in GASplits. Geneva is gallery #1.
Contracts. GAGalleryRegistry.
Flow. Curator signs in → registers gallery → multisig verifies → curator can co-sign drops → drop appears on /galleries/:slug.
Impact. Physical-digital bridge. Galleries get curation + a cut, artists get reach + IRL exhibition.
Risks. Verification bottleneck (mitigated: weekly multisig review SLA). Metric: verified galleries per quarter, drops per gallery.
F11 — Frozen artifact pipeline
Impl. GitHub Action in each artist repo: on tag push (v*), it runs npm ci && npm run build (or just zips the static dir), uploads zip to R2 via Worker signed URL, calls Worker /v1/projects/:id/freeze which pins to Pinata + web3.storage, returns CID, writes CID into D1 and into the artist repo's freeze.json. Must succeed before mint.
Contracts. GAProject.setBaseFrozenCID(cid) called once by artist post-freeze.
Flow. Artist tags v1.0.0 → Action runs → freeze.json updated → mint enabled.
Impact. This is what makes mints permanent even if GitHub or the artist disappears. It's also the legal/curatorial credibility layer.
Risks. IPFS pin loss (mitigated: dual-pin Pinata + web3.storage, monthly health-check job re-pins missing CIDs). Metric: % of mints with verified dual-pin.
F12 — Discovery, search, leaderboards
Impl. D1 FTS5 index over users.handle, projects.title/description, briefs.title/body_md. Leaderboards are materialized views refreshed every 5 min: top artists by mint volume, by remix count, by collab count.
Contracts. None.
Flow. /explore → tabs (artists / projects / briefs / galleries) → search box + filters (engine, industry, has-mints).
Impact. Discovery = retention. Without it, the platform is just a list of profiles you have to know to find.
Risks. Gaming the leaderboards (mitigated: weight by unique-collector count, not raw volume). Metric: explore CTR, search-to-follow conversion.

  --ga-type-lg:  20px;
  --ga-type-xl:  28px;

  // Borders — 1px, never more
  --ga-border: 1px solid var(--ga-rule);

UI rules. No box shadows. No rounded corners except on avatars (50%) and pills (9999px). One accent color, used only on primary CTAs and active nav. Tables and cards use 1px rules, never fills. Hover state = underline OR accent color, never both. Never use the brand red on body text. Sub-pixel borders (hairline) on dark mode only.
Typography. Mono for: code, addresses, hashes, IDs, monospaced tabular data. Sans for: prose, navigation, headings. No serif anywhere.
Logotype. Wordmark only at MVP: GA lockup in monospace, letterspaced 0.04em, all caps. SVG at assets/img/ga-mark.svg. No icon-only variant until we have brand recognition to support it.
Imagery. All artwork covers are square 1:1, max 1080px, AVIF first then WebP fallback. No stock photography, ever. Cover thumbnails are auto-generated from the sketch's first frame at freeze time.

const KEY='ga-replit-v1';
let state=JSON.parse(localStorage.getItem(KEY)||'{}');
function save(){localStorage.setItem(KEY,JSON.stringify(state))}
let cur=0;

function id(pi,ti){return 'p'+pi+'t'+ti}

function progress(){
  let done=0,tot=0;
  phases.forEach((p,pi)=>p.tasks.forEach((_,ti)=>{tot++;if(state[id(pi,ti)])done++;}));
  document.getElementById('prog').textContent=done+' / '+tot;
  document.getElementById('bar').style.width=tot?Math.round(done/tot*100)+'%':'0%';
}

function tabs(){
  const el=document.getElementById('tabs');
  el.innerHTML='';
  phases.forEach((p,pi)=>{
    const b=document.createElement('button');
    b.className='tab'+(pi===cur?' active':'');
    const d=p.tasks.filter((_,ti)=>state[id(pi,ti)]).length;
    b.textContent=p.short+' '+d+'/'+p.tasks.length;
    b.onclick=()=>{cur=pi;tabs();list()};
    el.appendChild(b);
  });
}

function list(){
  const el=document.getElementById('list');
  el.innerHTML='';
  phases[cur].tasks.forEach((t,ti)=>{
    const sid=id(cur,ti);
    const done=!!state[sid];
    const card=document.createElement('div');
    card.className='task-card'+(done?' done':'');

    const head=document.createElement('div');
    head.className='task-head';
    head.innerHTML='<span class="task-num">'+String(ti+1).padStart(2,'0')+'</span><span class="task-title">'+t.t+'</span><input type="checkbox" class="task-cb"'+(done?' checked':'')+' />';

    const body=document.createElement('div');
    body.className='task-body';
    body.innerHTML='<div class="prompt-label">Replit prompt</div><div class="prompt-box">'+t.p+'</div><button class="copy-btn">Copy prompt</button><div class="done-when"><strong>Done when:</strong> '+t.d+'</div>';

    head.querySelector('input').addEventListener('change',function(e){
      e.stopPropagation();
      state[sid]=this.checked;
      save();
      card.classList.toggle('done',this.checked);
      progress();tabs();
    });
    head.addEventListener('click',function(e){
      if(e.target.type==='checkbox')return;
      body.classList.toggle('open');
    });
    body.querySelector('.copy-btn').addEventListener('click',function(){
      navigator.clipboard.writeText(t.p).then(()=>{
        this.textContent='Copied!';
        setTimeout(()=>this.textContent='Copy prompt',1500);
      });
    });
    card.appendChild(head);card.appendChild(body);el.appendChild(card);
  });
}

tabs();list();progress();
