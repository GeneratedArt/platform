17. Homepage Design — /
This is the single most important UI surface. It must feel like a contemporary art gallery crossed with a modern Web3 marketplace. Not like a crypto bro casino.
17.1 Above the fold

Full-bleed hero (100vh):

Left 60%: a live-rendering iframe of a curated-featured generative work, auto-rotating every 30s through the current Editor's Choice set (4-6 pieces). The piece itself is the hero, zero UI overlay.
Right 40%: editorial text panel

Tagline (huge, Fraunces Display / Cal Sans / serif): "The open platform for generative art."
Sub (Inter body): "Artist-owned. Code-audited. Chain-anchored. Forever forkable."
Three pill buttons stacked: Explore works → /projects, Apply as artist → /studio/apply, Register gallery → /galleries/apply
Small caption with tiny live counters: 2,104 works · 387 artists · 28 galleries · 14,922 editions minted (polled from /api/stats, updates every 60s)


The Connect Wallet pill sits top-right (header is sticky, transparent over hero, blurred once scrolled)



17.2 Editor's Choice strip

Horizontal scroll of 8-12 cards
Each card: live-rendering preview (not static image — actually animates if the piece animates), artist handle, piece title, GA Score pill, price
Click → project page

17.3 Latest Drops

Two-column grid, reverse chronological
Filter chips at top: All / Live mint / Recently sold out / Open for collab
Each tile: live preview, artist, title, mint progress bar, price, GA Score

17.4 Featured Artists

Horizontal carousel, 6 cards at a time
Card: artist avatar, handle, work count, one featured piece (static capture OK here for perf), "View →"

17.5 Featured Galleries

Map view (Leaflet + OpenStreetMap tiles, no Mapbox token needed) showing gallery pins globally
Click a pin → side-panel with gallery preview, active exhibitions, link to /galleries/:slug
Below map: 3-card row of "Now exhibiting" galleries with their current showcase config as a rotating preview

17.6 Community Pulse
Three-column row:

Recent Ratings — live feed of just-signed ratings (EIP-712 verified), "0x72…AF rated Rivers 5 stars"
Recent Collabs — new collaborations accepted on-chain
Recent Agreements — new gallery↔artist agreements signed

17.7 Manifesto snippet
Short pull-quote from the manifesto, "Read the manifesto →" link to /manifesto.
17.8 Footer

Four columns: Platform (manifesto, docs, fork on GitHub), Community (Discord, governance, curator elections), Resources (artist handbook, gallery guide, smart contracts, API), Legal (terms, licenses)
Bottom row: "GeneratedArt is a public good. No company. No HQ. Run by its community. ◉"
Version + commit hash pulled from build env

17.9 Visual language

Palette: pure black #000, pure white #fff, one accent (default #00d084 — tweakable by governance). No gradients, no shadows beyond subtle 1px borders.
Typography: display = Fraunces or Cal Sans (variable, 300-900); body = Inter; mono = JetBrains Mono
Motion: prefers-reduced-motion respected; else micro-animations on hover/load (80ms, ease-out)
Density: breathe — no dense info grids; treat the homepage like a museum's entry hall
Dark mode default, light mode toggle in header (persists to localStorage, never via KV — pure client-side)

17.10 Performance budget
Lighthouse ≥ 95 on mobile + desktop. LCP < 2.0s. Cumulative layout shift < 0.05. Only the hero iframe defers; everything else is critical-path SSR from Jekyll.
