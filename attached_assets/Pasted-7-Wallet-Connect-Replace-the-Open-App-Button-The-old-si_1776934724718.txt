7. Wallet Connect — Replace the "Open App" Button
The old site had an "Open App" button top-right. Remove it. Replace with a Connect Wallet button that lives in the site header on every page (Jekyll and Astro).
7.1 Connect flow (mimics the reference screenshots)

Disconnected state: black pill button labeled Connect top-right.
On click, open a modal (Reown AppKit default styled to our brand):

MetaMask (with fox icon)
Coinbase Wallet (with blue square icon)
Other Wallets (WalletConnect v2 — shows a grid of Rainbow, Trust, Argent, Phantom, etc.)
Bottom link: I don't have a wallet → /docs/wallets onboarding guide


On wallet selection, trigger the connection, then immediately trigger a SIWE (Sign-In With Ethereum, ERC-4361) signature request. The SIWE message includes a nonce from /api/auth/nonce. Success sets a session cookie (httpOnly, SameSite=Strict, 30-day sliding).

7.2 Connected state
Header pill shows 0x7291...Af9FF (first 4, last 4 chars) with a bell icon for notifications. Click → dropdown menu:

Profile → /profile/:address
Studio (if role ≥ artist) → /studio
Gallery Console (if role = gallery) → /gallery-console
Dashboard → /dashboard
Account Management → /dashboard/settings
--- divider ---
Primary: Ethereum / Base (shows current chain + truncated address with copy icon)
Add Secondary Wallet → supports Tezos, Solana, Ethereum L1 (aligns with fxhash's "Add Tezos wallet" pattern)
--- divider ---
Disconnect (white button, top of section)

7.3 Implementation
Use Reown AppKit (formerly WalletConnect Modal) configured with:
tsimport { createAppKit } from '@reown/appkit';
import { WagmiAdapter } from '@reown/appkit-adapter-wagmi';
import { base, baseSepolia, mainnet } from '@reown/appkit/networks';

export const appKit = createAppKit({
  adapters: [new WagmiAdapter({ networks: [base, baseSepolia, mainnet], projectId })],
  networks: [base, baseSepolia, mainnet],
  projectId: import.meta.env.VITE_REOWN_PROJECT_ID,
  metadata: {
    name: 'GeneratedArt',
    description: 'The open platform for generative art',
    url: 'https://generatedart.com',
    icons: ['https://generatedart.com/assets/icon-512.png'],
  },
  features: { analytics: false, email: false, socials: false },
  themeMode: 'dark',
  themeVariables: {
    '--w3m-accent': '#00d084',
    '--w3m-font-family': 'Inter, sans-serif',
    '--w3m-border-radius-master': '12px',
  },
});
The button is a web component (<w3m-button balance="hide" />) — drops into both Jekyll pages and Astro islands identically.
7.4 First-time wallet → role flow

New wallet connects → SIWE signs → /api/auth/siwe/verify creates a users row with role='collector'.
User visits /dashboard → onboarding card: "You're a collector. Want to publish art? [Become an Artist] Want to exhibit? [Register as Gallery]"
Clicking Artist or Gallery triggers a role-application flow (see §11 and §13).
