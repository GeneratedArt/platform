A platform we'd want to publish on ourselves.

GeneratedArt is a marketplace and home for code-based generative art. Everything that ships here is a sketch — a JavaScript or shader program that renders a unique output for every collector who mints it. The repo is the artwork. The artist owns the contract. The platform is shared infrastructure, not a landlord.

We started this because the existing options each gave up something we weren't willing to give up. Centralised marketplaces hold the keys, dictate royalties, and de-platform without warning. Pure on-chain venues are beautiful but inaccessible to most artists. The middle ground — open, curatable, transparent, with a real physical-world endpoint — was empty.

What we believe

The repo is the artwork.

A sketch is its source. Mints reference an immutable commit, not a JPEG. If the platform disappears, the work still runs — pull the repo, open the file, render in any browser.

The artist owns the contract.

Every collection deploys to the artist's address on Base. We never custody keys, never take a cut at the contract level, never pause transfers. The platform is a discovery and curation surface, not a gatekeeper.

Curation is human.

Anyone can publish a repo. Featured work is curated by a rotating council of artists who put their names on the choice. No engagement algorithm. No trending tab.

There is a room.

GeneratedArt has a physical gallery in Geneva. Selected work is printed, projected, or displayed on dedicated hardware. The internet part and the room part feed each other.

Where it runs

Static front-end on GitHub Pages. Hono on Cloudflare Workers for the API. D1 + KV + R2 + Queues at the edge. ERC-721 contracts on Base. Wallets via WalletConnect. Pinning via IPFS. No central database, no auth provider, no platform that can pull the rug.
