GeneratedArt is built in the open. The fastest way to reach the team is on GitHub or in the community Discord — both are public, both are archived. Email is best for press, gallery proposals, and partnership enquiries.

Code & bugs

Open an issue on github.com/generatedart. Pull requests welcome. The whole platform — site, Worker, contracts — lives in one monorepo.

Community

Day-to-day conversation lives in the GeneratedArt Discord. Studio sessions, sketch reviews, mint announcements, and the occasional argument about colour spaces.

Email

For press, partnership, and gallery proposals: hello@generatedart.com. We reply within a few working days. Please don't email feature requests — open a GitHub issue instead so the conversation is public.

The gallery

GeneratedArt's physical room is in Geneva. Drop-in hours, mint nights, and printed editions are announced on the homepage and in Discord. Address shared on confirmation of attendance.

We don't run a contact form. Public channels keep replies accountable and let the community help when we're slow.
