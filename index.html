GeneratedArt is where AI Creative Coders build the models that make the art.

Curate a dataset. Train a custom AI art model. Or hand-code a p5.js, three.js, WebGL, or GLSL sketch. Either way the artifact is code with disclosed provenance — pinned to IPFS, minted on Base, never a rented aesthetic from a closed prompt box.

The Code Sketch path

Hand-writing p5.js, three.js, or GLSL is still a fully respected craft here — the three steps below are how it works. Training a custom AI art model instead? See the Model path →

01 — Repo as project

Your GitHub repo is the canonical project.

Sign in with your wallet, name a project, and GA spins up a real public repo from a template under GeneratedArt-artists/. Source CID is pinned at mint time so the on-chain tokenURI resolves to the exact code that produced the edition.

02 — Studio in the browser

Edit, capture, commit — in one tab.

The on-site Studio runs your code in a sandboxed iframe with a deterministic seed, captures the canvas to R2, and commits straight back to your repo. ⌘S to commit, ⌘E to export.

03 — Mint on Base

Open editions, on-chain royalties.

Each project deploys its own ERC-721 (EIP-1167 minimal proxy) on Base Sepolia with EIP-2981 royalties. The Worker is a thin coordinator; the wallet sends every transaction. tokenURI = ipfs://{cid}/?seed={hex}.

Manifesto · short version

Code is the artifact — a sketch, or the model that made it. The chain is the ledger. The community is the curator.

  • No closed plugins. Hand-written p5.js, three.js, WebGL, GLSL — readable in the repo.
  • No hidden middlemen. Stewards rotate; treasury splits are on-chain.
  • No undisclosed models. Every AI art model publishes its base model, training method, and dataset note.
  • Physical-digital bridge. Token holders can claim a print at the Geneva gallery.
