v0.1.0 · hackathon · base sepolia

Code-based generative art, owned by the people who write it.

A community-run platform and on-chain marketplace for hand-written p5.js, three.js, WebGL and GLSL. Mint editions on Base, run sketches in the browser, bridge digital tokens to physical prints at the Geneva gallery.

Explore projects Open studio

01 — Repo as project

Your GitHub repo is the canonical project.

Submit a public repo URL, sign in with your wallet, and GA pins the source CID, computes a deterministic tokenId from (repoOwner, repoName, commitSha), and renders a card on /projects.

02 — Studio in the browser

Sketch directly. Hash, capture, mint.

The on-site Studio runs your code with a deterministic seed, captures the canvas, lets you tweak parameters and submit the resulting iteration as a candidate edition for any project you've created.

03 — Mint on Base

Open editions. Patron splits. No middlemen.

Editions mint to a fixed-supply ERC-721 on Base Sepolia. Royalties and patron splits are encoded on-chain via EIP-2981 and a project-level splitter. Source code is the asset; the chain is the ledger.

Manifesto · short version

Code is the artifact. The browser is the gallery. The chain is the ledger. The community is the curator.

  • No closed plugins. Hand-written p5.js, three.js, WebGL, GLSL — readable in the repo.
  • No hidden middlemen. Stewards rotate; treasury splits are on-chain.
  • No ML-generated images. Tools that pattern-match human work are not welcome here.
  • Physical-digital bridge. Token holders can claim a print at the Geneva gallery.
